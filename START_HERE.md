## 🎯 Как запустить проект у себя:

### Вариант 1: Автоматически (самый простой)
```bash
# 1. Склонируй репозиторий
git clone <URL>
cd КП_БД

# 2. Установи PostgreSQL (если еще нет)

# 3. Запусти скрипт настройки БД
./setup_database.sh

# 4. Настрой backend
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Отредактируй .env - укажи свой пароль от PostgreSQL

# 5. Запусти backend (в ЭТОМ ЖЕ терминале, где активирован venv)
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
# ⚠️ НЕ ЗАКРЫВАЙ этот терминал! Backend должен работать постоянно

# 6. Открой ВТОРОЙ НОВЫЙ терминал (⌘+T на Mac или Ctrl+Shift+T на Windows)
# В новом терминале запусти frontend:
cd КП_БД/frontend
python3 -m http.server 3000
# ⚠️ НЕ ЗАКРЫВАЙ и этот терминал! Frontend должен работать постоянно

# 7. Открой браузер и перейди на http://localhost:3000
# Теперь у тебя должно быть ДВА открытых терминала:
#   Терминал 1: backend (порт 8000)
#   Терминал 2: frontend (порт 3000)
```

## 🗄️ Про базу данных

**Почему база не в репозитории?**
- Базы данных не хранятся в Git (это стандартная практика)
- Вместо этого используются SQL скрипты для создания структуры
- Сами данные хранятся в PostgreSQL на твоем компьютере

**Как это работает?**
1. На GitHub лежат только SQL скрипты (текстовые файлы с командами)
2. Когда ты запускаешь эти скрипты, PostgreSQL создает:
   - Таблицы (hotels, rooms, users, bookings и т.д.)
   - Вставляет тестовые данные (INSERT INTO ...)
   - Создает триггеры, функции, представления
3. Все эти данные сохраняются в PostgreSQL локально на твоем компьютере

**Что делать?**
1. Установи PostgreSQL
2. Выполни SQL скрипты из папки `database/` по порядку
3. Все! База создастся автоматически со всеми таблицами и тестовыми данными

**Где физически хранятся данные?**
- В папке данных PostgreSQL (обычно `/usr/local/var/postgres` на Mac)
- Ты можешь посмотреть их через DBeaver, pgAdmin или psql
- Это НЕ часть Git репозитория!

**Какие файлы выполнять:**
```
database/
├── init_schema.sql           ← Создает таблицы
├── 01_migration_add_users.sql ← Добавляет пользователей
├── 02_triggers.sql           ← Создает триггеры
├── 03_views.sql              ← Создает представления
├── 04_functions.sql          ← Добавляет функции
└── 05_test_data.sql          ← Загружает тестовые данные
```
