# 🏨 Руководство по запуску проекта

## Быстрый старт (для защиты КП)

### 1. Подготовка базы данных

```bash
# Создайте базу данных в PostgreSQL
createdb -U postgres hotel_booking

# Если у вас уже есть данные из DBeaver, выполните миграцию:
psql -U postgres -d hotel_booking -f database/01_migration_add_users.sql
psql -U postgres -d hotel_booking -f database/02_triggers.sql
psql -U postgres -d hotel_booking -f database/03_views.sql
psql -U postgres -d hotel_booking -f database/04_functions.sql

# Если нужны дополнительные тестовые данные:
psql -U postgres -d hotel_booking -f database/05_test_data.sql
```

**Тестовые пользователи после миграции:**
- **Системный админ**: `admin@hotel.com` / `admin123`
- **Админ отеля**: `admin.plaza@hotel.ru` / `hotel123`
- **Гости**: любой email из вашей таблицы guests / `password123`

### 2. Запуск Backend (FastAPI)

```bash
cd backend

# Создайте виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # Mac/Linux
# или: venv\Scripts\activate  # Windows

# Установите зависимости
pip install -r requirements.txt

# Настройте .env файл
cp .env.example .env
# Отредактируйте .env: укажите свои данные PostgreSQL

# Запустите сервер
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Backend будет доступен на `http://localhost:8000`
API документация (Swagger): `http://localhost:8000/docs`

### 3. Запуск Frontend

```bash
# Откройте новый терминал в папке frontend
cd frontend

# Запустите простой HTTP сервер
python3 -m http.server 3000

# Или используйте любой другой веб-сервер
```

Frontend будет доступен на `http://localhost:3000`

### 4. Проверка работы

1. Откройте `http://localhost:3000` в браузере
2. Нажмите "Войти" и используйте тестового пользователя
3. Проверьте список отелей
4. Проверьте функционал в зависимости от роли

## 🐛 Troubleshooting

### Ошибка подключения к БД:
- Проверьте, что PostgreSQL запущен
- Проверьте правильность данных в `.env`
- Проверьте, что база данных `hotel_booking` создана

### Ошибка CORS:
- Убедитесь, что backend запущен на порту 8000
- Проверьте настройки CORS в `backend/app/core/config.py`

### Ошибка 401 Unauthorized:
- Проверьте, что токен не истек (по умолчанию 30 минут)
- Попробуйте выйти и войти снова
