# Для Алены - как это всё работает 📚

## Где хранятся тестовые данные и таблицы?

### 1️⃣ Что лежит на GitHub:

```
КП_БД/
├── database/                    ← ВОТ ТУТ ВСЁ!
│   ├── init_schema.sql         ← Команды создания таблиц
│   ├── 05_test_data.sql        ← Команды вставки тестовых данных
│   └── другие скрипты...
├── backend/                     ← Код Python
├── frontend/                    ← Код HTML/JS
└── README.md
```

**В папке `database/` лежат TEXT файлы с SQL командами**, например:

```sql
-- В файле init_schema.sql:
CREATE TABLE hotels (
    hotel_id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    ...
);

-- В файле 05_test_data.sql:
INSERT INTO hotels (name, city, address, ...)
VALUES ('Grand Plaza Hotel', 'Москва', 'ул. Тверская, 1', ...);

INSERT INTO users (email, password_hash, first_name, ...)
VALUES ('admin@hotel.com', '$2b$12$hash...', 'Админ', ...);
```

### 2️⃣ Как данные попадают в базу:

```
GitHub репозиторий
       ↓
Твоя сокомандница клонирует
       ↓
У неё появляется папка database/ с SQL файлами
       ↓
Она запускает: psql -U postgres -d postgres -f database/init_schema.sql
       ↓
PostgreSQL читает команды из файла и СОЗДАЁТ таблицы
       ↓
Она запускает: psql -U postgres -d postgres -f database/05_test_data.sql
       ↓
PostgreSQL читает команды и ВСТАВЛЯЕТ данные
       ↓
Теперь в её локальном PostgreSQL есть ВСЕ таблицы и данные!
```

### 3️⃣ Где физически хранятся данные:

**НА ТВОЁМ КОМПЬЮТЕРЕ:**
- PostgreSQL хранит данные в своей папке (обычно `/usr/local/var/postgres` на Mac)
- Ты можешь посмотреть их через DBeaver или psql
- Это НЕ синхронизируется с GitHub!

**НА КОМПЬЮТЕРЕ СОКОМАНДНИЦЫ:**
- Будут СВОИ данные в ЕЁ PostgreSQL
- Создадутся из тех же SQL скриптов
- Будут ИДЕНТИЧНЫЕ таблицы и данные, как у тебя

### 4️⃣ Аналогия для понимания:

Представь, что SQL скрипты - это **РЕЦЕПТ ТОРТА** 🎂

```
GitHub = книга рецептов
         ↓
Ты склонировала рецепт
         ↓
Испекла торт (создала БД)
         ↓
Твой торт лежит у тебя дома (PostgreSQL на твоём Mac)

Сокомандница склонировала ТОТ ЖЕ рецепт
         ↓
Испекла СВОЙ торт (создала СВОЮ БД)
         ↓
Её торт лежит у НЕЁ дома (PostgreSQL на её компьютере)

Оба торта одинаковые, но физически разные!
```

## Про терминалы 💻

### Как это работает:

1. **Терминал 1 - Backend**:
   ```bash
   cd backend
   source venv/bin/activate
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   
   # Этот терминал "зависнет" - и ЭТО НОРМАЛЬНО!
   # Он работает и ждёт запросы от frontend
   ```

2. **Терминал 2 - Frontend**:
   ```bash
   # Открой НОВУЮ вкладку терминала (⌘+T на Mac)
   cd frontend
   python3 -m http.server 3000
   
   # Этот терминал тоже "зависнет" - это нормально!
   # Он раздаёт HTML/JS файлы браузеру
   ```

3. **Оба терминала должны работать одновременно**:
   ```
   Терминал 1: Backend слушает порт 8000
               ↓
   Терминал 2: Frontend слушает порт 3000
               ↓
   Браузер: открываешь localhost:3000
            Frontend запрашивает данные у Backend
            Backend отвечает данными из PostgreSQL
   ```

### Где открывать терминалы:

**В VS Code:**
1. Терминал 1: Уже открыт внизу
2. Терминал 2: Нажми **"+"** справа вверху панели терминала
   
**Или в обычном терминале Mac:**
1. Терминал 1: Открыт
2. Терминал 2: **⌘+T** (новая вкладка) или открой новое окно

## Что передаётся через Git? 📦

### ✅ Передаётся (текстовые файлы):
- Код Python (backend/)
- Код HTML/CSS/JS (frontend/)
- **SQL скрипты** (database/*.sql) - это рецепты для создания БД
- Документация (README.md и т.д.)
- Настройки (.env.example)

### ❌ НЕ передаётся:
- Сама база данных PostgreSQL (она на твоём компьютере)
- Виртуальное окружение Python (папка venv/)
- Реальный .env файл с паролями
- Временные файлы

## Короче говоря:

**GitHub = инструкция + чертежи**
- Как построить дом (SQL скрипты)
- Как запустить систему (код)

**PostgreSQL на твоём Mac = готовый дом**
- Уже построен
- Данные внутри

**PostgreSQL на компьютере сокомандницы = её дом**
- Она построит по тем же чертежам
- Будет выглядеть так же
- Но это другой дом!
